# C&C & Boxer Build

## Overview

This repository provides a cross-platform CMake build script and project files to compile and install the original C&C CCG parser (including the Boxer semantic tool) on Linux, Windows, and macOS.
It bundles the upstream C++ and Prolog sources from the original release,
obtained from [chrzyki/candc](https://github.com/chrzyki/candc),
and applies minimal adjustments.

## Purpose

- **Cross-Platform Builds**
  Enable out-of-the-box compilation on major operating systems (Linux, Windows, macOS) via CMake.
- **Upstream Preservation**
  Retain the original C&C and Boxer sources, preserving academic licensing and functionality.

## Build Instructions

1. **Install dependencies**
    * Debian based:
        ```bash
        sudo apt install swi-prolog cmake build-essential gcc g++
        ```
    * Fedora:
        ```bash
        sudo dnf install swi-prolog cmake gcc g++
        ```

1. **Clone the repository**

   ```bash
   git clone https://github.com/Alvaro-Kothe/candc-build.git
   cd candc-build
   ```

2. **Create a build directory**

   ```bash
   mkdir build && cd build
   ```

3. **Configure with CMake**

   ```bash
   cmake ..
   ```

4. **Build**
   ```bash
   cmake --build . --config Release
   ```

5. **Move binaries close to models**
    ```bash
    mv bin .. && cd ..
    ```
